## Getting Started


### Installation

```sh
cargo install --locked --git https://github.com/ShlomoScript/brainf--k
```

### Usage

To execute a program from a file, simply run
```sh
bf program.bf
```
from the command line
```sh
bf -s "<Your code here>"
```
To redirect output, use -o
```sh
bf program.bf -o out.txt
```
